# Service Management - Aplicação Angular 17+

Aplicação web moderna para gerenciamento de serviços construída com Angular 17+, Bootstrap 5.3+, RxJS, Jest e seguindo as melhores práticas de arquitetura e clean code.

## 🎯 Features

- ✅ **Angular 17+ Standalone Components** com Signals
- ✅ **Bootstrap 5.3+** para UI responsiva
- ✅ **RxJS 7+** com padrões reativos
- ✅ **TDD com Jest** - testes unitários robustos
- ✅ **Mock-First Architecture** - transição fácil para backend real
- ✅ **Mobile-First Responsive** - otimizado para todos os dispositivos
- ✅ **Lazy Loading** de features
- ✅ **TypeScript Strict Mode** - máxima segurança de tipos
- ✅ **ESLint + Prettier** - código consistente e formatado
- ✅ **Design System** completo com paleta de cores e animações
